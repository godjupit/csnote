## 1. 建表：实体完整性、参照完整性与用户定义完整性

来源：改编自书第 48～49 页习题 6（PDF 第 63～64 页）及第 50～51 页综合题①（PDF 第 65～66 页），对应 PPT 第 8～39 页。

## 2. 外码：哪些操作会破坏参照完整性

来源：依据书第 48～49 页习题 5、7（PDF 第 63～64 页）及第 51～53 页综合题②（PDF 第 66～68 页）改编，对应 PPT 第 20～26 页。

## 3. 约束命名、修改与空值

来源：依据 PPT 第 30～46 页及书第 50 页选择题（PDF 第 65 页）、第 51～53 页综合题②（PDF 第 66～68 页）选编。

## 4. 读触发器：事件、条件、动作与 OLD／NEW

来源：改编自 PPT 第 51～57 页的成绩修改日志例题。

已有 SC(sno, cno, grade)，主码为（sno，cno），grade 允许 NULL；日志表 SC_Log(sno, cno, old_grade, new_grade) 保存成绩修改前后的值。阅读下面的课件格式触发器，分别说明触发事件、触发时机、触发条件、触发动作以及 OldTuple 与 NewTuple 的含义；某次 UPDATE 明确修改 grade 列并影响三行，三行成绩分别由 60 改为 75、由 80 改为 85、由 NULL 改为 90，请判断会新增几条日志，逐条写出日志中的旧成绩与新成绩，并解释条件遇到 NULL 时会怎样。

```sql
CREATE TRIGGER Grade_Change_Log
AFTER UPDATE OF grade ON SC
REFERENCING OLD ROW AS OldTuple
            NEW ROW AS NewTuple
FOR EACH ROW
WHEN (NewTuple.grade >= OldTuple.grade + 10)
    INSERT INTO SC_Log(sno, cno, old_grade, new_grade)
    VALUES (OldTuple.sno, OldTuple.cno,
            OldTuple.grade, NewTuple.grade);
```

## 5. 写触发器：自动修正教授工资

来源：依据 PPT 第 59 页 BEFORE 行级触发器例题选编，参考书第 51、53 页综合题④（PDF 第 66、68 页）的行级触发器题型。

已有 Teacher(tno, tname, job, salary)，tno 为主码，job 与 salary 非空，salary 不能小于 0，目前没有“教授工资至少 4000”的 CHECK 约束。请按照课件格式编写一个 BEFORE INSERT OR UPDATE 行级触发器：当新记录的 job 为“教授”且 salary 小于 4000 时，直接把新记录的 salary 改为 4000，其余情况保持原值，不要在触发器中再对 Teacher 执行一条 UPDATE。说明应使用 NEW 还是 OLD、为什么要选择 BEFORE，并分别给出新记录为“教授，3500”“讲师，3500”“教授，5000”时最终保存的工资；最后说明这条触发器与 CHECK(job <> '教授' OR salary >= 4000) 在处理不合格输入时有什么区别。

## 6. 行级与语句级触发器：执行次数和失败处理

来源：依据 PPT 第 54、56、58、61 页自编，采用课件中的新插入行集合 Delta。

Student(sno, sname) 以 sno 为主码，StudentInsertLog(numbers) 保存每条插入语句新增的学生数量。阅读下面的语句级触发器：一条 INSERT 一次成功插入 3 名学生时，它执行几次、日志写入几行、numbers 是多少；若改成连续执行 3 条 INSERT 且每条插入 1 名学生，日志又如何变化？再假设另有一个无 WHEN 条件的 AFTER INSERT 行级触发器，它对一条成功插入 3 行的语句执行几次；如果插入语句成功执行但实际插入 0 行，行级与语句级触发器分别执行几次？最后说明 BEFORE 触发器、原始数据操作与 AFTER 触发器的先后顺序，以及某次触发动作失败时，本次语句已经产生的数据修改和日志修改应如何处理，按课件“本次语句的修改整体撤销”作答，不讨论异常被捕获的特殊情况。

```sql
CREATE TRIGGER Student_Count
AFTER INSERT ON Student
REFERENCING NEW TABLE AS Delta
FOR EACH STATEMENT
    INSERT INTO StudentInsertLog(numbers)
    SELECT COUNT(*) FROM Delta;
```
