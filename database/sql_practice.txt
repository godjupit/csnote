# SQL 基础练习（第一组）

根据 `sql_example.md` 的范围，使用 PostgreSQL 的 TPC-H 数据库完成下面 10 道查询题。本组
只列题目，不附答案。

说明：题干在各项要求旁标注了对应的数据库字段名；“数量”“平均值”等统计结果需要通过查询计算
，不是原表中已有的字段。

注意：实际品牌值是 `Brand#43` 这种形式，PostgreSQL 的 `LIKE` 区分大小写。

## 1. 模糊查询与排序

查询 `part` 表中，品牌 `p_brand` 以 `Brand#3` 开头、类型 `p_type` 包含 `BRASS` 的商品。
显示商品编号 `p_partkey`、名称 `p_name`、品牌 `p_brand`、类型 `p_type` 和尺寸 `p_size`，
按尺寸 `p_size` 降序、商品编号 `p_partkey` 升序排列。

select p_partkey, p_name, p_brand, p_type, p_size
from part
order by p_size, p_partkey Desc;

## 2. 分组统计与分组筛选

查询 `customer` 表中各市场区域 `c_mktsegment` 的客户数量（统计客户编号 `c_custkey`）和平
均账户余额（对 `c_acctbal` 求平均值）。显示市场区域及以上两项统计结果。只保留客户数量超
过 290 的区域，按平均账户余额降序排列。

select c_mktsegment, count(*), avg(c_acctbal)
from customer
group by c_mktsegment
having count(*) >= 290
order by avg(c_acctbal) desc;

## 3. 日期筛选与前 N 条记录

查询 `orders` 表中，下单日期 `o_orderdate` 在 1995 年内且优先级 `o_orderpriority` 包含
`URGENT` 的订单。显示订单编号 `o_orderkey`、日期 `o_orderdate`、优先级 `o_orderpriority`
 和总金额 `o_totalprice`，按总金额 `o_totalprice` 降序排列，只显示前 10 条。

select o_orderkey, o_orderdate, o_orderpriority, o_totalprice
from orders
where extract(year from o_orderdate)  = 1995
and o_orderpriority like '%URGENT%'
order by o_totalprice desc
limit 19;


## 4. 集合条件与算术表达式

查询 `lineitem` 表中，发货模式 `l_shipmode` 为 `AIR` 或 `TRUCK`、数量 `l_quantity` 大于
30 的明细。显示订单编号 `l_orderkey`、商品编号 `l_partkey`、数量 `l_quantity`，以及实际
金额（扩展价格 `l_extendedprice` 乘以（1 减折扣 `l_discount`））：
`l_extendedprice * (1 - l_discount)`，将实际金额命名为 `actual_amount`。


## 5. 按季度统计

统计 `lineitem` 表中，1995—1996 年每年各季度的发货明细数量，以发货日期 `l_shipdate` 为准
。显示年份（从 `l_shipdate` 提取）、季度（从 `l_shipdate` 提取）和明细数量（统计明细行数
），只保留明细数量超过 1000 的组，按年份、季度升序排列。

可使用例题涉及的 `EXTRACT` 提取年份和季度。

## 6. 三表连接

查询每个地区的供应商数量。连接 `region`、`nation`、`supplier`，显示地区名称 `r_name` 和
供应商数量，按供应商数量降序排列。

连接字段：`region.r_regionkey` 与 `nation.n_regionkey` 对应，`nation.n_nationkey` 与
`supplier.s_nationkey` 对应。供应商数量通过统计供应商编号 `s_suppkey` 得到。


## 7. 连接、聚合与 HAVING

查询每个国家的客户数量和平均账户余额。连接 `nation` 和 `customer`，显示国家名称 `n_name`
、客户数量（统计客户编号 `c_custkey`）及平均账户余额（对 `c_acctbal` 求平均值），只保留
平均账户余额大于 4000 的国家。

连接字段：`nation.n_nationkey` 与 `customer.c_nationkey` 对应。

select nation.n_name, count(customer.c_custkey),avg(customer.c_acctbal)
from nation, customer
where nation.n_nationkey = customer.c_nationkey
group by nation.n_nationkey, nation.n_name
having avg(customer.c_acctbal) > 4000;

## 8. 存在与不存在的子查询

分别编写两条 SQL：

1. 查询至少下过一笔订单的客户，显示客户编号 `c_custkey` 和名称 `c_name`，每个客户只出现
一次。
2. 查询从未下过订单的客户，显示客户编号 `c_custkey` 和名称 `c_name`。

涉及 `customer` 和 `orders` 两张表，客户编号 `customer.c_custkey` 与订单所属客户编号
`orders.o_custkey` 对应。尝试分别使用 `EXISTS` 和 `NOT EXISTS`。

select customer.c_name
from customer
where exists (
    select 1
    from orders
    where orders.o_custkey = customer.c_custkey
);

select c.c_custkey, c.c_name
from customer c
where not exists(
    select 1
    from orders o
    where o.o_custkey = c.c_custkey
);


## 9. 自连接与去除重复组合

在 `customer` 表中查询国家编号 `c_nationkey` 相同、且市场区域 `c_mktsegment` 不同的客户
对。显示两个客户的编号 `c_custkey`、名称 `c_name` 和共同的国家编号 `c_nationkey`。要求不
能将客户与自身配对，同一对客户只出现一次，例如出现 `(1, 2)` 后不能再出现 `(2, 1)`。

select c1.c_custkey, c2.c_custkey
from customer c1, customer c2
where c1.c_nationkey = c2.c_nationkey
and c1.c_mktsegment != c2.c_mktsegment
and c1.c_custkey < c2.c_custkey;

## 10. 相关子查询

在 `orders` 表中查询订单总金额 `o_totalprice` 高于该客户自身平均订单金额（对相同客户编号
 `o_custkey` 的所有订单的 `o_totalprice` 求平均值）的订单。显示订单编号 `o_orderkey`、客
户编号 `o_custkey` 和订单总金额 `o_totalprice`，按客户编号 `o_custkey` 升序、订单总金额
`o_totalprice` 降序排列。

SELECT o1.o_orderkey, o1.o_custkey, o1.o_totalprice
from orders o1
where o1.o_totalprice > 
(
select avg(o2.o_totalprice)
from orders o2
where o2.o_custkey = o1.o_custkey
)
order by o_custkey, o_totalprice desc;

# 第四组：综合查询

## 1. 1996 年 7 月的销售冠军

查询 1996 年 7 月的销售冠军，即该月销售额最高的供应商。
以 lineitem 表的发货日期（l_shipdate）确定月份，
销售额为扩展价格（l_extendedprice）乘以（1 减折扣 l_discount）的合计。
结果显示销售冠军 ID（l_suppkey），以及该供应商在 1996 年 7 月的销售额
（命名为 sales_amount）；如有并列冠军，全部显示。

select sum(l_extendedprice * (1 - l_discount)) as price
from lineitem
where l_shipdate > '1996-07-01'
and l_shipdate < '1996-07-31'
group by l_suppkey
having sum(l_extendedprice * (1 - l_discount))  >=
(
select sum(l_extendedprice * (1 - l_discount)) as price
from lineitem
where l_shipdate > '1996-07-01'
and l_shipdate < '1996-07-31'
group by l_suppkey
order by price
limit 1);

## 4. 读触发器：事件、条件、动作与 OLD／NEW

选课表 SC(sno, cno, grade) 记录学号、课程号和成绩，以（sno，cno）为主码，成绩可以为空。
日志表 SC_Log(sno, cno, old_grade, new_grade) 用来保存成绩修改前后的值。
请阅读下面的触发器，指出：它在什么操作发生时触发，是操作前还是操作后，满足什么条件才记录日志，记录到哪里。
再解释 OldTuple 和 NewTuple 分别表示什么。
现在一条 UPDATE 修改了 3 行成绩：60 改为 75，80 改为 85，NULL 改为 90。
请判断哪几行会记录日志，写出日志中的旧成绩和新成绩，并说明旧成绩为 NULL 时，WHEN 条件能否成立。

CREATE TRIGGER Grade_Change_Log
AFTER UPDATE OF grade ON SC
REFERENCING OLD ROW AS OldTuple
            NEW ROW AS NewTuple
FOR EACH ROW
WHEN (NewTuple.grade >= OldTuple.grade + 10)
    INSERT INTO SC_Log(sno, cno, old_grade, new_grade)
    VALUES (OldTuple.sno, OldTuple.cno,
            OldTuple.grade, NewTuple.grade);

## 6. 行级与语句级触发器：执行次数和失败处理

学生表 Student(sno, sname) 以学号 sno 为主码。
日志表 StudentInsertLog(numbers) 用来记录每条 INSERT 新增了多少名学生。下面是课件格式的语句级触发器。
如果一条 INSERT 成功插入 3 名学生，触发动作执行几次，日志增加几行，numbers 是多少？

CREATE TRIGGER Student_Count
AFTER INSERT ON Student
REFERENCING NEW TABLE AS Delta
FOR EACH STATEMENT
    INSERT INTO StudentInsertLog(numbers)
    SELECT COUNT(*) FROM Delta;

关系模式；字段含义
S(SNO, SNAME, STATUS, CITY)；供应商编号、名称、状态、所在城市
P(PNO, PNAME, COLOR, WEIGHT)；零件编号、名称、颜色、重量
J(JNO, JNAME, CITY)；工程编号、名称、所在城市
SPJ(SNO, PNO, JNO, QTY)；哪个供应商向哪个工程供应哪种零件，以及数量

S、P、J 的主码分别是 SNO、PNO、JNO，SPJ 以（SNO，PNO，JNO）为主码，三个编号分别参照对应表，
QTY 为正数。S 和 J 都有 CITY 列，写连接条件时应指明它属于哪张表。J 中可以有尚未收到任何零件的工程。
本组只要求根据表结构写表达式，不需要列出具体查询结果。

### 书写 13：给某工程供过货

### 书写 14：同时限制工程与零件

### 书写 15：连接零件表查询颜色

查询向工程 J1 供应过红色零件的供应商编号，只输出 SNO。请写关系代数表达式。

### 书写 16：排除不符合要求的工程

查询从未收到过“天津供应商供应的红色零件”的工程，只输出 JNO。其他城市供应的红色零件不影响条件，天津供应商供应的非红色零件也不影响条件。
请使用差运算，并保留完全没有供货记录的工程。

### 书写 17：工程用齐指定供应商供应过的零件

查询至少使用了供应商 S1 供应过的全部零件种类的工程，只输出 JNO。S1 供应过的零件种类按其所有 SPJ 记录确定；
工程使用这些零件时，不要求也由 S1 供货，允许额外使用其他零件。请使用除运算，并假设 S1 至少供应过一种零件。

## 公共表：教师、系与工作（书写 18～20）

参考书第 24～27 页（PDF 第 39～42 页）的教师工资、重命名和外连接题型，使用 Teacher(Tno, Tname, Tage, Tsex)、Department(Dno, Dname, DTno)、Work(Tno, Dno, Year, Salary)。
DTno 表示系主任的教师号，可以为空；Work 保存当前工作记录，每名教师最多一条，Tno 为其主码。系可以没有教师，

请使用关系代数表达式，可以把 Work 重命名为两个副本，不使用聚集函数 MAX。

### 书写 19：左外连接：保留全部教师

查询所有教师的姓名和所在系名称，显示 Tno、Tname、Dname。没有 Work 记录的教师也要出现，系名称显示 NULL。
请使用左外连接写关系代数表达式。

### 书写 20：右外连接：保留全部系

## 手算题

### 手算 1：投影后为什么行数减少

关系 R(A, B, C) 的元组为（a1，b1，c1）、（a2，b1，c1）、（a3，b2，c2）。请分别列出 π_B(R)、π_{B,C}(R)、π_{A,B}(R) 的结果，
写出各自的行数与列数；再判断 σ_{A='a1'}(π_B(R)) 是否有定义，并说明原因。

### 手算 2：并、差、交与笛卡尔积

关系 R(X, Y) 为 {(1,a),(2,b)}，S(X, Y) 为 {(2,b),(3,c)}。请列出 R∪S、R−S、R∩S 和 R×S 的结果。
笛卡尔积结果的列用 R.X、R.Y、S.X、S.Y 区分。

### 手算 3：等值连接、自然连接与悬浮元组

关系 R(A, B) 为 {(1,x),(2,x),(3,z)}，S(B, C) 为 {(x,10),(y,20)}。
请列出按 R.B=S.B 进行等值连接和自然连接的结果，比较两者列数；指出两侧哪些是悬浮元组，再列出自然左外连接和自然右外连接的结果，
未匹配部分填 NULL。

### 手算 4：象集与除运算

关系 R(X, Y) 为 {(a,p1),(a,p2),(a,p3),(b,p1),(c,p1),(c,p2)}，
S(Y) 为 {p1,p2}。请写出 a、b、c 在 R 中的 Y 象集，求 R÷S，并解释一个 X 值多对应了 p3 是否影响它满足条件。

### 手算 5：结果的行数与列数

非空关系 R(A,B,C,D) 有 m 行，S(A,B,C,D) 有 n 行，两者对应列的域相同；另有 T(C,D,E,F) 有 k 行，
其中 m、n、k 都大于 0。请分别给出 R∪S、R−S、π_{A,B}(R)、σ_{A=10}(R)、R×T、R⋈T 的结果列数，
以及每个结果行数的最小值和最大值。A 所在的域允许取值 10，关系无额外的码或取值范围约束。
