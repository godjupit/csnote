# SQL 基础练习（第一组）

根据 `sql_example.md` 的范围，使用 PostgreSQL 的 TPC-H 数据库完成下面 10 道查询题。本组
只列题目，不附答案。

说明：题干在各项要求旁标注了对应的数据库字段名；“数量”“平均值”等统计结果需要通过查询计算
，不是原表中已有的字段。

注意：实际品牌值是 `Brand#43` 这种形式，PostgreSQL 的 `LIKE` 区分大小写。

## 1. 模糊查询与排序

查询 `part` 表中，品牌 `p_brand` 以 `Brand#3` 开头、类型 `p_type` 包含 `BRASS` 的商品。
显示商品编号 `p_partkey`、名称 `p_name`、品牌 `p_brand`、类型 `p_type` 和尺寸 `p_size`，
按尺寸 `p_size` 降序、商品编号 `p_partkey` 升序排列。

select p_partkey, p_name, p_brand, p_type, p_size
from part
order by p_size, p_partkey Desc;

## 2. 分组统计与分组筛选

查询 `customer` 表中各市场区域 `c_mktsegment` 的客户数量（统计客户编号 `c_custkey`）和平
均账户余额（对 `c_acctbal` 求平均值）。显示市场区域及以上两项统计结果。只保留客户数量超
过 290 的区域，按平均账户余额降序排列。

select c_mktsegment, count(*), avg(c_acctbal)
from customer
group by c_mktsegment
having count(*) >= 290
order by avg(c_acctbal) desc;

## 3. 日期筛选与前 N 条记录

查询 `orders` 表中，下单日期 `o_orderdate` 在 1995 年内且优先级 `o_orderpriority` 包含
`URGENT` 的订单。显示订单编号 `o_orderkey`、日期 `o_orderdate`、优先级 `o_orderpriority`
 和总金额 `o_totalprice`，按总金额 `o_totalprice` 降序排列，只显示前 10 条。

select o_orderkey, o_orderdate, o_orderpriority, o_totalprice
from orders
where extract(year from o_orderdate)  = 1995
and o_orderpriority like '%URGENT%'
order by o_totalprice desc
limit 19;


## 4. 集合条件与算术表达式

查询 `lineitem` 表中，发货模式 `l_shipmode` 为 `AIR` 或 `TRUCK`、数量 `l_quantity` 大于
30 的明细。显示订单编号 `l_orderkey`、商品编号 `l_partkey`、数量 `l_quantity`，以及实际
金额（扩展价格 `l_extendedprice` 乘以（1 减折扣 `l_discount`））：
`l_extendedprice * (1 - l_discount)`，将实际金额命名为 `actual_amount`。


## 5. 按季度统计

统计 `lineitem` 表中，1995—1996 年每年各季度的发货明细数量，以发货日期 `l_shipdate` 为准
。显示年份（从 `l_shipdate` 提取）、季度（从 `l_shipdate` 提取）和明细数量（统计明细行数
），只保留明细数量超过 1000 的组，按年份、季度升序排列。

可使用例题涉及的 `EXTRACT` 提取年份和季度。

## 6. 三表连接

查询每个地区的供应商数量。连接 `region`、`nation`、`supplier`，显示地区名称 `r_name` 和
供应商数量，按供应商数量降序排列。

连接字段：`region.r_regionkey` 与 `nation.n_regionkey` 对应，`nation.n_nationkey` 与
`supplier.s_nationkey` 对应。供应商数量通过统计供应商编号 `s_suppkey` 得到。


## 7. 连接、聚合与 HAVING

查询每个国家的客户数量和平均账户余额。连接 `nation` 和 `customer`，显示国家名称 `n_name`
、客户数量（统计客户编号 `c_custkey`）及平均账户余额（对 `c_acctbal` 求平均值），只保留
平均账户余额大于 4000 的国家。

连接字段：`nation.n_nationkey` 与 `customer.c_nationkey` 对应。

select nation.n_name, count(customer.c_custkey),avg(customer.c_acctbal)
from nation, customer
where nation.n_nationkey = customer.c_nationkey
group by nation.n_nationkey, nation.n_name
having avg(customer.c_acctbal) > 4000;

## 8. 存在与不存在的子查询

分别编写两条 SQL：

1. 查询至少下过一笔订单的客户，显示客户编号 `c_custkey` 和名称 `c_name`，每个客户只出现
一次。
2. 查询从未下过订单的客户，显示客户编号 `c_custkey` 和名称 `c_name`。

涉及 `customer` 和 `orders` 两张表，客户编号 `customer.c_custkey` 与订单所属客户编号
`orders.o_custkey` 对应。尝试分别使用 `EXISTS` 和 `NOT EXISTS`。

select customer.c_name
from customer
where exists (
    select 1
    from orders
    where orders.o_custkey = customer.c_custkey
);

select c.c_custkey, c.c_name
from customer c
where not exists(
    select 1
    from orders o
    where o.o_custkey = c.c_custkey
);


## 9. 自连接与去除重复组合

在 `customer` 表中查询国家编号 `c_nationkey` 相同、且市场区域 `c_mktsegment` 不同的客户
对。显示两个客户的编号 `c_custkey`、名称 `c_name` 和共同的国家编号 `c_nationkey`。要求不
能将客户与自身配对，同一对客户只出现一次，例如出现 `(1, 2)` 后不能再出现 `(2, 1)`。

select c1.c_custkey, c2.c_custkey
from customer c1, customer c2
where c1.c_nationkey = c2.c_nationkey
and c1.c_mktsegment != c2.c_mktsegment
and c1.c_custkey < c2.c_custkey;

## 10. 相关子查询

在 `orders` 表中查询订单总金额 `o_totalprice` 高于该客户自身平均订单金额（对相同客户编号
 `o_custkey` 的所有订单的 `o_totalprice` 求平均值）的订单。显示订单编号 `o_orderkey`、客
户编号 `o_custkey` 和订单总金额 `o_totalprice`，按客户编号 `o_custkey` 升序、订单总金额
`o_totalprice` 降序排列。

SELECT o1.o_orderkey, o1.o_custkey, o1.o_totalprice
from orders o1
where o1.o_totalprice > 
(
select avg(o2.o_totalprice)
from orders o2
where o2.o_custkey = o1.o_custkey
)
order by o_custkey, o_totalprice desc;

# 第二组：子查询与相关子查询（7 道）

每题写之前，先想两件事：
外层逐行检查什么？内层需要计算或查找什么？

## 1. 高于所有订单平均金额的订单

表：orders

查询订单总金额 o_totalprice 高于整张订单表平均总金额的订单。

显示：
  订单编号 o_orderkey
  客户编号 o_custkey
  订单总金额 o_totalprice

先想：检查不同订单时，内层计算的平均值需要变化吗？
select o_orderkey
from orders o1
where o1.o_totalprice > (
    select avg(o2.o_totalprice)
    from orders o2
);

## 2. 属于中国的客户

表：customer、nation

使用子查询，查询国家名称 n_name 为 'CHINA' 的客户。

相关字段：
  客户所属国家：customer.c_nationkey
  国家编号：nation.n_nationkey

显示客户编号 c_custkey、客户名称 c_name。

先想：能不能先在内层找到中国的国家编号，
再让外层筛选客户？
select c.c_custkey
from customer c
where c.c_nationkey = 
(
    select n.n_nationkey
    from nation n
    where n.n_name = 'CHINA'
);

## 3. 至少有一笔大额订单的客户

表：customer、orders

查询至少有一笔订单总金额 o_totalprice 大于 200000 的客户，
每个客户只出现一次。

相关字段：
  客户编号：customer.c_custkey
  订单所属客户：orders.o_custkey

显示客户编号 c_custkey、客户名称 c_name。
尝试使用 EXISTS。

先想：内层既要检查订单金额，还需要保证这笔订单属于谁？

select c.c_custkey
from customer c
where exists (
    select 1
    from orders o2
    where o2.o_custkey = c.c_custkey
    and o2.o_totalprice > 200000
);

## 4. 从未下过大额订单的客户

表和显示字段与第 3 题相同。

查询不存在任何一笔总金额大于 200000 的订单的客户。
没有下过订单的客户也要包含在结果中。

尝试使用 NOT EXISTS。

注意：“没有大额订单”与“至少有一笔小额订单”是不同的条件。

## 5. 高于自己平均订单金额的订单

表：orders

查询订单总金额 o_totalprice
高于该订单所属客户的平均订单金额的订单。

显示：
  订单编号 o_orderkey
  客户编号 o_custkey
  订单总金额 o_totalprice

按客户编号升序、订单总金额降序排列。

对照第 1 题想：外层换成另一个客户的订单时，
内层平均值应该怎样变化？

## 6. 高于本国平均余额的客户

表：customer

查询账户余额 c_acctbal
高于与自己属于同一个国家的所有客户平均余额的客户。

显示：
  客户编号 c_custkey
  客户名称 c_name
  国家编号 c_nationkey
  账户余额 c_acctbal

先想：第 5 题通过客户编号关联内外层，
这一题应该通过哪个字段关联？

## 7. 客户数量超过平均水平的市场区域

在 customer 表中，哪些市场区域的客户数量超过所有市场区域的平均客户数量，
结果显示市场区域（c_mktsegment）、客户数量（命名为 customer_count），
并按客户数量降序排列。
select c1.c_mktsegment
from customer c1
group by c1.c_mktsegment
having count(*) > 
(
    select count(*) * 1.0 / count(distinct c2.c_mktsegment)
    from customer c2
);

select c1.c_mktsegment
from customer c1
having count(*) > 10
group by c1.c_mktsegment;

# 第四组：综合查询

## 1. 1996 年 7 月的销售冠军

查询 1996 年 7 月的销售冠军，即该月销售额最高的供应商。
以 lineitem 表的发货日期（l_shipdate）确定月份，
销售额为扩展价格（l_extendedprice）乘以（1 减折扣 l_discount）的合计。
结果显示销售冠军 ID（l_suppkey），以及该供应商在 1996 年 7 月的销售额
（命名为 sales_amount）；如有并列冠军，全部显示。
