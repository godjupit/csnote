# 第八章 数据库编程习题

本组共 7 道题，先不附答案。建议优先完成第 1～5 题，再做第 6～7 题。这里的优先级是根据本章课件与习题内容作出的练习建议，不代表老师划定的考试范围。

参考《数据库系统概论（第6版）习题解析与实验指导》第八章，题目按课件范围重新选编或改编；每题注明来源，不直接照搬书中的答案。书页指印刷页码，PDF 页指阅读器中从 1 开始计数的页码。

SQL 编程统一按 PostgreSQL 语法作答，过程化部分使用 PL/pgSQL；不要混用书中示例里的 MySQL 或其他数据库语法。表名与字段名按题干使用，不加双引号。

## 1. 递归查询：查找全部先修课程（重点）

来源：参考书第 83～84 页习题 1（PDF 第 98～99 页），PPT 第 19～25 页；将多先修课情形整理为两张表。

课程表 Course(cno, cname) 保存课程编号和名称，cno 为主码；先修关系表 Prerequisite(cno, prereq_cno) 保存“课程 cno 的直接先修课为 prereq_cno”，两个编号共同作为主码并分别参照 Course。一门课程可以有多门直接先修课，也可以是多门课程的先修课。现有课程 C1～C6，名称分别为“程序设计基础”“数据结构”“数据库系统概论”“操作系统”“离散数学”“毕业设计”，先修记录为（C2，C1）、（C3，C2）、（C3，C4）、（C4，C1）、（C4，C5），C6 没有先修课，整个先修关系不存在环。请使用 WITH RECURSIVE 查询 C3 的全部直接和间接先修课程，显示课程编号（cno）与课程名称（cname），同一课程通过不同路径找到时只显示一次，不输出 C3 本身，并按课程编号升序排列；再说明初始查询、递归查询和终止条件分别是什么，以及为什么只连接固定次数不能适应任意层数的先修关系。

## 2. 递归查询：补齐没有订单的日期（重点）

来源：PPT 第 28～29 页日期序列课堂练习，重新明确表结构与输出要求。

订单表 Orders(oid, odate, amount) 中，oid 为主码，odate 为 DATE 类型，amount 为非空 NUMERIC 类型，每行表示一笔订单。现有订单（1，2026-01-01，100）、（2，2026-01-01，50）、（3，2026-01-03，80）、（4，2026-01-05，120），没有其他订单。请使用 WITH RECURSIVE 生成 2026-01-01 至 2026-01-05 的完整日期序列，并统计每一天的订单数量和订单总金额，显示日期（d）、订单数量（order_count）和总金额（total_amount），没有订单的日期也必须显示，数量与金额均为 0，按日期升序排列。

## 3. 过程化 SQL：变量、查询结果与游标（重点）

来源：PPT 第 37～57 页，围绕书第 83 页列出的过程化 SQL 与游标知识点自编。

已有选课表 SC(sno, cno, grade)，主码为（sno，cno），grade 可为空，非空值在 0～100 之间。现要处理三个任务：取得全表非空成绩的平均值；取得学生 S1 选修课程 C1 的课程号和成绩；逐行查看 S1 的全部选课记录，并对每门课程输出“及格”“不及格”或“未出成绩”。请分别说明每个查询可能返回几行、每行有几列，应如何接收或处理结果，为什么“返回两列”不等于“必须使用游标”，以及零行查询结果与返回一行 NULL 的结果有什么不同；再写出一个 PL/pgSQL 匿名块，显式声明、打开、读取并关闭游标，完成第三个任务，成绩大于等于 60 判为及格，并用 RAISE NOTICE 输出课程号和状态。S1 没有选课记录时，程序应正常结束，不输出课程状态。

## 4. 存储过程：使用游标统计成绩分布（重点）

来源：改编自书第 84～85 页习题 2①（PDF 第 99～100 页），对应 PPT 第 50～73 页。

已有 Course(cno, cname) 和 SC(sno, cno, grade)，Course 的主码为 cno，SC 的主码为（sno，cno），grade 可为空，非空值在 0～100 之间。请编写存储过程 course_grade_distribution，以课程编号 p_cno 为输入参数，显式使用游标逐行读取该课程的成绩，分别统计 [90,100]、[80,90)、[70,80)、[60,70)、[0,60) 五个分数段以及未出成绩的人数，并通过 RAISE NOTICE 输出六项统计结果。六个计数器初始值均为 0，不存在的课程应报告异常；课程存在但没有选课记录时，六项统计均输出 0。写出存储过程定义，并给出查询课程 C1 成绩分布的调用语句。

## 5. 存储函数：将百分制成绩转换成等级（重点）

来源：改编自书第 84～86 页习题 2③（PDF 第 99～101 页），对应 PPT 第 76～78 页；改为返回等级，保留原始成绩。

已有 SC(sno, cno, grade)，主码为（sno，cno），grade 为可空整数。请编写返回 TEXT 的 PL/pgSQL 存储函数 grade_level(p_grade INT)，将 90～100 分转换为 A、80～89 分转换为 B、70～79 分转换为 C、60～69 分转换为 D、0～59 分转换为 E，输入 NULL 时返回 NULL，输入小于 0 或大于 100 的分数时报告异常。再在一条 SELECT 中调用该函数，显示每条选课记录的学号、课程号、原始成绩和等级，按学号、课程号升序排列，不修改 SC 中的 grade；最后说明该任务为什么适合使用函数，以及存储函数与存储过程在返回值声明和调用方式上有什么区别。

## 6. 存储过程：按参数调整工资

来源：改编自书第 92 页补充习题 2①b（PDF 第 107 页），对应 PPT 第 59～73 页。

员工表 Employee(eid, ename, salary) 以 eid 为主码，salary 为非空 NUMERIC 类型且不能小于 0。请编写存储过程 raise_low_salary，以工资标准 p_threshold 为输入参数，把工资低于该标准的员工工资统一调整为该标准，等于或高于标准的员工保持不变。参数为 NULL 或小于 0 时应报告异常，标准为 0 时允许正常执行，没有员工需要调整时也应正常结束。写出过程定义及按标准 8000 调用的语句，并说明这个批量更新是否必须逐行使用游标。

## 7. JDBC：参数化查询与结果集处理

来源：依据书第 88～91 页习题 4 的 JDBC 数据访问题型（PDF 第 103～106 页）和 PPT 第 93～103 页自编，缩小为单数据库查询。

已有 Employee(eid, ename, salary)，eid 为主码，ename 与 salary 非空。请编写一个 Java 方法，连接参数作为方法参数传入，使用 JDBC 和 PreparedStatement 查询工资大于等于给定标准 minSalary 的员工，显示员工编号、姓名和工资，并按工资降序、员工编号升序输出；不要把 minSalary 直接拼接到 SQL 字符串中。查询没有返回记录时应正常结束，连接、语句和结果集资源在正常结束或抛出异常时都必须释放。请在代码中体现建立连接、设置参数、执行查询、遍历结果集和释放资源的过程，并说明 ResultSet.next() 的作用以及本题应使用 executeQuery 还是 executeUpdate。
